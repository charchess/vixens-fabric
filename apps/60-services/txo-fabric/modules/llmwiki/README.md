# LLMWiki module

**Status:** placeholder; absent and disabled by default.

This optional module will provide a user-owned knowledge-workspace experience for
Markdown. Its v0 design is intentionally undecided: navigation, editing,
versioning, search, backlinks/graph and semantic/vision capabilities require a
separate design decision.

Markdown is the provisional source of truth. Any future index or AI-derived view
must be disposable and must not become an authorization bypass.
